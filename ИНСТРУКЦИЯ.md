# Бесплатный автоответчик Instagram @dlya.urokov23

Отвечает на **комментарии** (и пишет автору в директ каталог) и на **сообщения в директе**.
Работает в облаке GitHub каждые ~10 минут, **компьютер может быть выключен**. Бесплатно и без лимитов.

Что он делает:
| Пишут | Ответ в комментарии | В директ |
|---|---|---|
| «Фонетика», «Хочу», «+», «Сколько стоит?» | «Отправила каталог игр вам в директ 📩…» | ссылка на каталог + WhatsApp |
| «Класс 😍», 🔥, ❤️ | «Спасибо большое 🥰 Каталог — в шапке» | — |
| «Что за программа?» | «Расскажу подробнее в директ 📩» | про курс (программу не называет) |
| «курс» | «Отправила информацию о курсе…» | цены курса + WhatsApp |
| только @отметки друзей | пропускает | — |
| Директ: «сколько стоит» | — | все цены + каталог + WhatsApp |
| Директ: первое «Здравствуйте» | — | «Отвечу лично в ближайшее время» + каталог |

- В комментариях цен **нет никогда** — только в директе.
- Если под комментарием уже есть ваш ответ (ваш, SMMBOT или бота) — бот его не трогает.
- Если в директе вы сегодня уже переписывались с человеком — бот молчит, дальше отвечаете вы.
- Все тексты — в файле `replies.py`, их легко поменять.

## Подключение (один раз, ~20 минут)

### 1. Приложение Meta (бесплатно)
1. Откройте https://developers.facebook.com → **Мои приложения** → **Создать приложение**.
2. Сценарий: **«Управление сообщениями и контентом в Instagram»** (Instagram API).
3. В приложении: **Instagram → Настройка API с входом через Instagram**.
4. В разделе **«Создать маркеры доступа»** нажмите **«Добавить аккаунт»** → войдите в @dlya.urokov23 → разрешите все пункты.
5. Нажмите **«Создать маркер»** — скопируйте длинный токен (начинается с `IG…`). **Никому его не показывайте.**
6. Там же включите разрешения: `instagram_business_basic`, `instagram_business_manage_comments`, `instagram_business_manage_messages`.

> ⚠️ Аккаунт должен быть **профессиональным** (Автор или Бизнес) — у вас уже так.
> Если в директе бот не может отвечать незнакомым людям — нужно нажать «Опубликовать» приложение / пройти проверку (App Review) для `instagram_business_manage_messages`. Это бесплатно, Claude поможет пройти. Комментарии работают сразу.

### 2. Репозиторий на GitHub
1. На https://github.com (аккаунт kik198195-lab) → **New repository** → имя `insta-bot` → **Public** (тогда минуты бесплатны без лимита; токен всё равно скрыт).
2. Загрузите все файлы из папки `D:\dowlands\insta-bot` (вместе с папкой `.github`).
3. **Settings → Secrets and variables → Actions**:
   - **Secrets** → New: `IG_TOKEN` = токен из шага 1.
   - **Secrets** → New: `GH_PAT` = личный токен GitHub (Settings профиля → Developer settings → Fine-grained token → доступ к репозиторию `insta-bot`, права *Secrets: Read and write*). Нужен, чтобы бот сам продлевал токен Instagram каждую неделю.
   - **Variables** → New: `DRY_RUN` = `1` — **пробный режим**: бот только пишет в журнал, что ответил бы.

### 3. Проверка и запуск
1. **Actions → Instagram автоответчик → Run workflow**. Откройте запуск — увидите строки `[ПРОБНО] коммент @… → …`.
2. Если ответы нравятся — поменяйте переменную `DRY_RUN` на `0`. Всё, бот работает 🎉
3. SMMBOT можно отключить (или оставить — двойных ответов не будет).

Чтобы остановить бота: **Actions → Instagram автоответчик → ⋯ → Disable workflow**.
